Marklume 隱私權政策

生效日期：2026-11-24　最後更新：2026-11-24

本政策網址：https://kumahua.github.io/marklume/privacy/zh-TW/

一句話：Marklume 不蒐集、不上傳任何資料。 它在你的電腦上讀取並排版你打開的 Markdown 文件；開發者沒有伺服器，也收不到任何東西。

1. Marklume 在你的電腦上會讀取什麼

為了把文件排版出來，Marklume 會在你的瀏覽器裡讀取以下內容。這些資料只在你的電腦上處理，不會傳送給開發者或任何第三方：

  • 你打開的 .md／.markdown 分頁的文字內容。網址結尾不是這兩種的頁面，Marklume 會立刻停止，不讀取內容。
  • 目前資料夾的檔案與子資料夾名稱（「檔案」分頁使用），以及目前文件的網址或路徑。

2. 存在你電腦上的資料

位置 內容 保留多久
chrome.storage.local 閱讀設定：主題、字級、內文寬度、側欄寬度與分頁、各項開關（例如自動重新整理、封鎖遠端媒體、顯示隱藏檔案） 直到你變更設定或移除擴充功能
chrome.storage.local 你展開過的資料夾網址（最多 300 筆，用來記住檔案樹的展開狀態） 超過 300 筆時刪除最舊的；移除擴充功能時一併刪除
chrome.storage.session 資料夾列表的暫存（30 秒）與檔案樹的捲動位置 關閉瀏覽器即清除
  • 不使用 chrome.storage.sync，所以設定不會同步到你的 Google 帳號或其他裝置。
  • 移除 Marklume 時，Chrome 會刪除上面所有資料。

3. 網路連線

Marklume 沒有自己的伺服器，不使用分析或追蹤工具，也不從網路載入程式碼（所有程式庫都打包在擴充功能裡）。它只會在以下三種情況連線，而且目的地都是文件本身所在的位置：

  1. 自動重新整理：重新讀取你正在看的本機檔案（file://），偵測存檔。資料不會離開你的電腦。可以在設定面板關閉。
  2. 資料夾列表：讀取目前資料夾的列表。本機資料夾在你的電腦上讀取；網路上的文件則向同一台伺服器要該資料夾的列表頁。
  3. 修正文字編碼：網路上的文件沒有宣告編碼時，向同一台伺服器重新讀取這份文件，讓中文正確顯示。

第 2、3 項的請求不帶 cookie、登入資訊或用戶端憑證，也不跟隨轉址。

4. 文件裡的遠端圖片、影片與音訊

如果文件引用了其他網站的圖片、影片或音訊，預設會像一般網頁一樣，從那些網站直接載入。這是文件本身的內容，那些網站可能會依它們自己的政策看到你的 IP 位址等連線資訊。

如果你不想自動連線，可以在設定面板開啟「封鎖遠端媒體」（預設關閉）。開啟後，遠端媒體會先顯示為佔位框，你可以一個一個點開，或按「全部載入」。

5. 權限說明

權限 為什麼需要
storage 把設定存在 chrome.storage.local，並把資料夾列表短暫存在 chrome.storage.session
scripting 確認分頁是 Markdown 文件後，把排版程式與樣式放進該分頁；設定面板也用它查看目前分頁的狀態
主機權限：file:///* 讀取本機 .md 檔與它所在的資料夾列表，並在存檔後自動重新整理。另外需要你在擴充功能詳細資料開啟「允許存取檔案網址」
主機權限：http://*/*、https://*/* Markdown 文件可能放在任何網站上。Marklume 用它讀取網址結尾是 .md／.markdown 的頁面、讀取同一台伺服器的資料夾列表，以及修正文字編碼

快捷鍵（commands，預設 Alt+Shift+M）不是權限，只用來切換預覽與原始碼。

6. 兒童

Marklume 不蒐集任何人的資料，包括兒童。

7. 政策變更

如果日後資料處理方式有任何改變，我們會先更新本頁與商店說明，並在擴充功能內明確告知，才會開始新的做法。
