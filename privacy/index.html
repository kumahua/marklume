Marklume Privacy Policy

Effective date: 2026-11-24　Last updated: 2026-11-24

Policy URL: https://kumahua.github.io/marklume/privacy/

In one sentence: Marklume collects nothing and uploads nothing. It reads and lays out the Markdown documents you open, right in your browser. The developer has no server and receives nothing.

1. What Marklume reads on your computer

To lay out a document, Marklume reads the following inside your browser. This is processed only on your computer and is never sent to the developer or any third party:

  • The text of .md / .markdown tabs you open. On pages whose URL doesn't end in one of those, Marklume stops immediately and doesn't read the content.
  • The names of files and subfolders in the current folder (for the Files tab), and the current document's URL or path.

2. Data stored on your computer

Where What How long
chrome.storage.local Reading settings: theme, font size, text width, sidebar width and tab, and toggles such as auto-reload, Block remote media and Show hidden files Until you change them or remove the extension
chrome.storage.local Addresses of folders you expanded (up to 300, so the file tree remembers what was open) The oldest are dropped past 300; all are deleted when you remove the extension
chrome.storage.session A 30-second cache of folder listings and the file tree's scroll position Cleared when you close the browser
  • Marklume doesn't use chrome.storage.sync, so settings are not synced to your Google account or other devices.
  • When you remove Marklume, Chrome deletes all of the above.

3. Network connections

Marklume has no server of its own, uses no analytics or tracking, and loads no code from the internet (every library is bundled in the extension). It connects only in these three cases, and always to where the document itself lives:

  1. Auto-reload: re-reads the local file (file://) you're viewing to notice when you save it. Nothing leaves your computer. You can turn this off in the settings panel.
  2. Folder listings: reads the current folder's listing. Local folders are read on your computer; for documents on the web, Marklume asks the same server for that folder's listing page.
  3. Text encoding fix: when a web server doesn't declare a document's encoding, Marklume re-reads that document from the same server so that non-Latin text such as Chinese displays correctly.

Requests in cases 2 and 3 send no cookies, login details or client certificates, and don't follow redirects.

4. Remote images, video and audio in documents

If a document links to images, video or audio hosted on other websites, they load from those websites by default, just as they would on any web page. That content is part of the document, and those sites may see connection details such as your IP address under their own policies.

If you'd rather not connect automatically, turn on Block remote media in the settings panel (off by default). Remote media then appears as placeholders that you can load one at a time, or all at once with Load all.

5. Permissions

Permission Why it's needed
storage Keeps settings in chrome.storage.local and briefly caches folder listings in chrome.storage.session
scripting After confirming a tab is a Markdown document, adds the layout code and styles to that tab; the settings panel also uses it to check the current tab's state
Host permission file:///* Reads local .md files and their folder listings, and reloads after you save. You also need to turn on "Allow access to file URLs" in the extension's details
Host permissions http://*/*, https://*/* Markdown files can be hosted on any website. Marklume uses this to read pages whose URL ends in .md / .markdown, read folder listings from the same server, and fix text encoding

The keyboard shortcut (commands, Alt+Shift+M by default) is not a permission; it only switches between the preview and the source.

6. Children

Marklume doesn't collect data from anyone, including children.

7. Changes to this policy

If the way Marklume handles data ever changes, we'll update this page and the store listing, and tell you clearly inside the extension, before the new practice starts.
